📊 Customer Churn Analysis | End-to-End Data Pipeline & Dashboard
An end-to-end data analytics project simulating a real-world enterprise workflow. This project transforms raw customer dataset into actionable business insights using **Excel, Python (Pandas & NumPy), MySQL, and Power BI.

---
🛠️ Tech Stack & Tools
* **Data Cleaning & Manipulation:** Microsoft Excel, Python (Jupyter Notebook, Pandas, NumPy)
* **Database & Querying:** MySQL Workbench (SQL)
* **Data Visualization & Analytics:** Power BI (DAX, Interactive Dashboards)
* **Version Control:** Git & GitHub
---

```text
[Raw Dataset] ──► [Excel & Python (Pandas/NumPy)] ──► [MySQL Database] ──► [Power BI Dashboard]
                      (Data Cleaning & EDA)          (SQL Analysis)       (DAX & Visual Reports)
